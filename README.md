# BFTG — Beautiful Fancy Telegram GUI

A skill for Telegram bot UI: premium custom emoji in messages, and custom emoji icons (including color) on inline/reply keyboard buttons.

## What it does

- Lookup table of custom emoji IDs for common icons (settings, profile, lock, check, cross, etc.).
- Correct `<tg-emoji>` HTML tag format for messages.
- Correct `icon_custom_emoji_id` usage for keyboard buttons.
- Reply keyboard button color IDs (blue/red/green) and when to use them.

## Install

Tell your agent:

```
Install the skill from github.com/crubly/bftg-skill
```
