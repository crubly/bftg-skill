# BFTG — Beautiful Fancy Telegram GUI

A skill for Telegram bot UI (aiogram 3.30+, Bot API 9.4+): premium custom emoji in messages, custom emoji icons on inline/reply keyboard buttons, and button color via the `style` field.

## What it does

- Lookup table of custom emoji IDs for common icons (settings, profile, lock, check, cross, etc.).
- Correct `<tg-emoji>` HTML tag format for messages.
- Correct `icon_custom_emoji_id` usage for keyboard buttons.
- Correct `style` field usage (`primary`/`success`/`danger`) for button color, and when to use it.

## Install

Tell your agent:

```
Install the skill from github.com/crubly/bftg-skill
```
